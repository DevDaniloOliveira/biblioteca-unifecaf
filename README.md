# Biblioteca Digital UniFECAF

Primeira versão do site da Biblioteca Digital UniFECAF, desenvolvida para a disciplina **Design Web**, usando apenas **HTML e CSS**.

**Site:** https://devdanilooliveira.github.io/biblioteca-unifecaf/

## Seções

Menu · Hero · Sobre a nossa biblioteca · Banner · Nossos livros · As unidades · Contatos · Rodapé

## Estrutura

```
biblioteca-unifecaf/
├── index.html
├── css/
│   └── style.css
├── assets/
│   └── imagens/
└── docs/
    ├── relatorio.md
    └── capturas/
```

## Como abrir

Abra o arquivo `index.html` no navegador. Não há dependências nem etapa de build.

## Relatório

O relatório com as decisões de design, paleta, tipografia, responsividade e acessibilidade está em [docs/relatorio.md](docs/relatorio.md).
